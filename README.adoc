**Docker**

1. What is Docker?
2. What is a Docker Image?
3. What is a Docker Container?
4. Run a Docker Container on your local OS.
5. Show the Docker command to:
    a. List all images
    b. List all containers
    c. Create a container
    d. Stop/start a container
    e. Build an image
    f. Delete an image
    g. Delete a container
6. Show how to manage ports on a Docker container.

Bonus: Explain the purpose of multi-stage builds, volume management.
