# Navigate the file system

| Command | Description |
| --- | --- |
| `ls` | Lists files and folders in the current folder. |
| `cd` | Changes folder. |
| `pwd` | Shows the current working folder. |

---

# Working files and folders

| Command | Description |
| --- | --- |
| `mkdir` | Creates a new folder. |
| `rm` and `rmdir` | Deletes files or folders. |
| `cp` | Copies files or folders. |
| `mv` | Moves or renames files and folders. |

---

# Get information about files

| Command | Description |
| --- | --- |
| `cat` | Shows the contents of a file. |
| `echo` | Writes a text string to the terminal or to a file. |
| `touch` | Creates an empty file or updates the timestamp of an existing file. |
