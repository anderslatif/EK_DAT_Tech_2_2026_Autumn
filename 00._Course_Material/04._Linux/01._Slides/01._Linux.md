# Package Management in AlmaLinux

AlmaLinux is a community-driven fork of CentOS, which is a fork of Red Hat Enterprise Linux (RHEL).

This means that it uses the `dnf` package manager, which is a newer version of `yum`.

While the package manager to install software is different, the Linux commands you will learn in this course are the same across all distributions.

Let's try it out locally in a container this week.

---

# Let's run AlmaLinux in a container

Install it with bash:

```bash
docker run -it almalinux:9 bash
```

The image is stripped bare so we need to install `procps-ng` that contains the `ps` command even though it usually comes with most *nix distros:

```bash
dnf install -y procps-ng
```

The `ps` command allows us to see what processes are running. It usually comes installed in most *nix distros.

---

# Running and Killing Processes

Everything running on Linux is a **process** with a **PID** — a process ID.

Your shell is a process too.

```bash
sleep 3 &
```

`sleep 3` is a command that idles for 3 seconds.

The `&` runs it in the background, so you get your prompt back.

Bash answers with `[<job_number>] <PID>`

`PID` (process ID) is a unique identifier for the process.

---

# List Processes


List all processes:

```bash
ps aux
```

`a`: show processes for **a**ll users.

`u`: show the **u**ser/owner of the process.

`x`: show processes not attached to a terminal (background processes).

*Try running the command while ommiting some or all of the flags.*


---

# List and kill a process

Let's assume that `ps aux` looks like this this:

```bash
USER         PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
root          61  0.0  0.0   4484  1624 pts/0    Ss   14:24   0:00 bash
--coreutils-prog-shebang=sleep /usr/bin/sleep 300
```

And we want to kill the sleep process with PID 61 (or whatever PID you were given for the sleep command), we can do it with:

```bash
kill 61
```

It will inform us that there are no more processes with that PID.

```
bash: kill: (61) - No such process
[1]   Done                    sleep 3
[2]   Done                    sleep 3
```
