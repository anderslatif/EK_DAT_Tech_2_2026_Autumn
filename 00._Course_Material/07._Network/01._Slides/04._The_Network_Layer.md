# The Network Layer (also called the Internet Layer)

Last week we learned about the network layer, which is responsible for routing data packets across networks.

**Protocols**: IP (IPv4, IPv6)", ICMP...

---


# ICMP (Internet Control Message Protocol)

IP's messenger. Routers and hosts use ICMP to report errors and answer diagnostic requests.

| Message | Used for |
|---|---|
| Echo Request / Echo Reply | `ping` |
| Destination Unreachable | The host or port could not be reached. |
| Time Exceeded | The packet's TTL ran out. Used by `traceroute`. |

TTL (Time To Live): every IP packet has a counter that each router decreases by `1`. At `0` the router drops the packet and sends back an ICMP Time Exceeded message. This stops packets from looping forever.

# Ping

`ek.dk` blocks ping (ICMP Echo Requests), so you cannot ping it.

Instead, let's ping Google's DNS server:

```bash
$ ping 8.8.8.8
```

Remember: `CTRL+C` to stop the ping (Windows stops after 4).

*What is the packet loss percentage? What is the average round-trip time?*

# Trace the route to Google

Trace route, will show each hop a packet takes to reach a destination.

It sends packets with TTL `1`, `2`, `3`… and each router that drops one reveals itself.

Maybe you will notice some of your ISP's infrastructure along the way.

**MacOS / Linux**: 

```bash
$ traceroute google.com
```

**Windows**: 

```bash
$ tracert google.com
```
