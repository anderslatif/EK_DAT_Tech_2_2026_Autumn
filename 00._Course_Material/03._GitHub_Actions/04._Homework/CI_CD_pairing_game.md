# CI/CD Pairing Game

Play the [CI/CD Pairing Game](https://anderslatif.github.io/ci_cd_pairing_game) to understand the concepts of Continuous Integration and Continuous Deployment.

You will be presented with pipeline steps that you have never heard of before. There is value in you learning about these through the exercise and you will encounter them in the future.

Misplaced cards will be returned to the pile. Continue playing until the pile is empty.
