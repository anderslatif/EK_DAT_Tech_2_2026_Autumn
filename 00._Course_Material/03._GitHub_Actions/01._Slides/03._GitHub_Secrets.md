# GitHub Secrets

A way to define secret values in GitHub. 

This could contain credentials, API keys etc.

GitHub Actions can use them in their workflows.

---

# Set up the project

1. Create a new repository.

  Give it a good name like `tech2_learning_github_secrets`.

2. Create a workflow file called `secrets.yml`.

  *Where should the workflow file be created?*

<details> 
  <summary>Answer</summary>
   .github/workflows/
</details>

*What **must** the workflow file contain?*

---

# What every workflow file needs

Every workflow file needs three things:

* `name`

* `on` (trigger): (push, pull_request, workflow_dispatch)

* `jobs`: list of names and the machine to run on (`runs-on: ubuntu-latest`).


---

# Create a basic workflow file

In `.github/workflows/secrets.yml` create a workflow file with the following content:

```yaml
name: Secrets

on:
  push:
    
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
        - name: print secret
          run: echo "The secret is ${{ secrets.MY_SECRET }}"
```

---

# Create a secret

1. Click on **Settings** tab in the top right corner of your repository.

2. Click on **Secrets and variables** in the left menu and select **Actions**.

3. Click on the button to create a **New repository secret**.

4. Give it the name `MY_SECRET` and any value you want.

5. Click on **Add secret**.

Note: Once you define a secret, it cannot be read by you again.

  <summary>Answer</summary>

</details>

# Create .env files

Add these two steps to the workflow file:

```bash
    - name: add secret to .env file
        run: echo "MY_SECRET=${{ secrets.MY_SECRET }}" >> .env
    - name: Count the amount of characters
        run: wc -c .env
```
