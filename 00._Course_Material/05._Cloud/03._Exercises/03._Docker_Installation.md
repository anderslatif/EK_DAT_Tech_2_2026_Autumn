# Docker setup on Virtual Machines

In this exercise, learn how to install Docker on your VM to be able to run Docker containers.

## Step 1: Docker installation script

Follow the official Docker installation guide for [CentOS](https://docs.docker.com/engine/install/centos/#install-using-the-repository) to install Docker.

Since AlmaLinux is a fork of CentOS, the installation steps are the same.

You could run the terminal commands manually but let's expand the lesson by showing how to create an installation script containing the commands and install from there.

On your VM, run `vi install-docker.sh` or `nano install-docker.sh` to create a new script file called `install-docker.sh` and paste the following content into it:

```bash
#!/bin/bash

sudo dnf -y install dnf-plugins-core
sudo dnf config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

sudo dnf install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

sudo systemctl enable --now docker

# This command adds the current user to the docker group, allowing you to run Docker commands without `sudo`.
sudo usermod -aG docker $USER

# Test out if it works
sudo docker run hello-world
```

When you have pasted the content, save and exit the file (in `vi`, you can do this by pressing `Esc`, then typing `:wq` and pressing `Enter`).

The command, `sudo systemctl status docker`, ensure that the Docker service is running even after a reboot.

## Step 2: Run the installation script

Try to run the script:

```bash
./install-docker.sh
-bash: ./install-docker.sh: Permission denied
```

You might've noticed that it was not possible to use tab to autocomplete the script name. This, along with the `Permission denied` error, is because the script must be given the permission to execute. 

To make it executable, run the following command:

```bash
chmod 700 install-docker.sh
```
This will give the script file the necessary permissions to be executed.

Now, run the script:

```bash
./install-docker.sh
```

When the installation is complete, check that Docker is installed correctly by running:


```bash
sudo systemctl status docker
```

You should see that the Docker service is active and running. Remember that `q` quits.
