# Why Docker Compose?

We learned Docker commands last week and created a `Dockerfile` to build a Docker image.

We are going to learn about a new file called `compose.yaml`.

We can interact with this file using `docker compose`.

Docker Compose enables the following: 

- Managing multiple containers.

- Configuring networks and volumes. 

- Simplifying the commands to start containers -> less commands to memorize. 


---

# A metaphor for Docker Compose

Docker Compose is also called a *container orchestrator*.

Last week we played 1 **instrument** at a time.

Today we will play multiple instruments at the same time: an **orchestra**.

The Docker Compose command will be our **conductor**.
