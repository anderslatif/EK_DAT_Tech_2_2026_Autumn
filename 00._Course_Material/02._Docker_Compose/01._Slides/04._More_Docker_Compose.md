# Networking

By default all services in Docker Compose join `default` network. 

This allows them to communicate with each other out of the box.

---

# Port-mapping

Considering this structure:

```text
<host_port>:<container_port>
```

If it is set for MySQL service like this:

```yaml
services:
  db:
    ports:
      - "3306:3306"
```

It means that it exposes MySQL on port `3306` of the host machine. 

---

# Port-mapping - Security concern

**Beware**: `3306:3306` makes changes to your firewall on your host machine (Linux) and exposes it to the outside world.

You don't want the internet to be able to access your database directly.

The solution is to explicitly bind the port to localhost only:

```yaml
services:
  db:
    ports:
      - "127.0.0.1:3306:3306"
```

Other containers, like the Spring Boot application, can still access the database on port `3306` because they are on the same network.
