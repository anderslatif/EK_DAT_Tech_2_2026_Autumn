# Bashcrawl Docker

Learn Linux commands by crawling through a maze of directories and files. 

---

## Get started

Create a `Dockerfile` with this content:

```Dockerfile
FROM alpine:latest

RUN apk add --no-cache curl bash tar wget grep

# Get the bashcrawl source code
RUN wget https://gitlab.com/slackermedia/bashcrawl/-/archive/stable-2024.02.09/bashcrawl-stable-2024.02.09.tar.gz && tar xzf bashcrawl-stable-2024.02.09.tar.gz && mv bashcrawl-stable-2024.02.09 bashcrawl

# Set the working directory (where the commands will be executed)
WORKDIR /bashcrawl/entrance

ENTRYPOINT ["/bin/bash"]
```

1. Build it. Do you remember how to build and run a Docker container from a Dockerfile?

2. Run it. And remember the `-it` flags when running the container in order to be able to interact with it.

Make sure that you are running Docker commands from where the `Dockerfile` is located.

Play the game as instructed:

> You will start in the directory `/entrance`. Print the contents of the scroll file using `cat scroll`. This will give you some initial instructions on how to play the game.

---

# Hints

Use the `history` command to see previously run commands.

Use `tree /bashcrawl/entrance` to look for newly unlocked rooms. It's a dungeon after all.

---

## Understand the Dockerfile

Bashcrawl game is a pre-existing game that only works for Linux.

Dockerizing it, enables anyone to run it on any OS. 

Try to understand each line of the `Dockerfile`.
