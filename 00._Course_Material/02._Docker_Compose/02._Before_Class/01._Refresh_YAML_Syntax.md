# Refresh YAML syntax

Solve these [8 exercises](https://anderslatif.github.io/yaml_tutorial/) to refresh your knowledge of YAML syntax.

You will be using YAML a lot the next couple of weeks so make sure that you have the syntax down.

Knowing the correct indentation (2 spaces) and the correct use of `-` for lists only will give you the ability to immediately solve workflow syntax problems rather than having to paste them to an LLM.
