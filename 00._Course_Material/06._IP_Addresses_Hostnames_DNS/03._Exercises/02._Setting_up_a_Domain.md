# Setting up a domain and DNS records

**Type**: Individual

**Hand-in**: A URL as part of Mandatory II.

---

## Introduction

In this exercise, you will buy a domain name from a domain registrar and set up DNS records that point it to a web server.

You can use any registrar, such as simply.com, one.com, namecheap.com or porkbun.com. Using one.com is optional, just as Azure is optional for VMs, but there is a voucher code for a free one.com domain in Teams.

> [!WARNING]
> **Cancel the domain subscription once your Mandatory II has been approved.** The domain renews automatically after the exams, and the renewal is not free. You will get a warning before it renews and a grace period to react but it's easier to just cancel the subscription ahead of time.

## Deploy a web server

1. Create a VM. See the [VM creation exercise](../../05._Cloud/03._Exercises/00._Create_a_VM.md) for instructions.

2. Install Docker. See [Docker Installation](../../05._Cloud/03._Exercises/03._Docker_Installation.md).

3. You can choose to redeploy your cross-disciplinary project or just a simple Docker nginx web server:

```bash
docker run -d -p 80:80 --name my-web-server nginx
```
