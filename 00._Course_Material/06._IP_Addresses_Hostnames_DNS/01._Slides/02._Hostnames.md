# Hostnames

*Why would one use hostnames (domain names) instead of IP addresses?*

---

# Why separate Names and IP Addresses?

| | Why | Example |
|---|---|---|
| **Memorability** | Domain names are easier for humans to remember than numerical IP addresses. | `nmap.org` vs `50.116.1.184` |
| **Flexibility** | IP addresses can change (e.g. when a website moves to a different server), but the domain name can remain the same. | Moving `nmap.org` to a new IP address doesn't require users to learn a new address. |
| **Scalability** | A single domain name can point to multiple IP addresses (for load balancing or redundancy). | Resolving to multiple servers to handle more traffic. |
| **Aliases** | Several names can lead to the same place. | `www.nmap.org`, `nmap.org` point to the same IP address. |

# Whois

To learn more about a domain name and the person / organization that registered it, you can use the `whois` command (not installed on Windows).

```bash
$ whois ek.dk
```

You can also try online tools like https://www.whois.com/

[Fun fact](https://entrepreneurship.babson.edu/magazine-archive/2016/02/05/the-man-who-bought-google-com/). A former Google employee purchased the google.com domain name for $12 in 2015 and held on to it for a minute. He was rewarded with the amount `$6,006.13` (which spells Google), which he donated to charity, and the domain name was returned to Google. Domains expire. The expiration date is visible in the whois output.

# What is Nmap?

Nmap ("Network Mapper") is a free and open-source tool for network discovery and security auditing.

It can be used to discover hosts on a computer network, thus creating a "map" of the network.

It can also be used as a port scanner to identify open ports and services running on a host.

Very useful debugging tool.

---

# Install Nmap

**MacOS**: 

```bash
$ brew install nmap
```

**Windows**:

1. Download the EXE installer from https://nmap.org/download.html
2. Run the installer and follow the prompts.

---

# Port Scanning with Nmap

```bash
$ nmap ek.dk
```

Nmap's own test server, this detects the software and version running on each open port:

```bash
$ nmap -sV scanme.nmap.org
```

---

# Discover devices on your computer / network

See what is open on your own machine:

```bash
$ nmap localhost
```

Find every device on your subnet without scanning ports (use your own network and CIDR from `ifconfig` / `ipconfig`):

```bash
$ nmap -sn 192.168.1.0/24
```
