# Course Preparation Work

Welcome to the course! Before we get started, there are a few things you need to do to prepare yourself.

---

## Prerequisites

All the terminal and git skills from last semester.

Make sure that you know how to create files, add and edit text content. Bonus if you can do it from the terminal: `nano`, `vim`, `notepad`.

---


## Install These


### Install Docker

[Install Docker Desktop](./Install_Docker_Desktop.md). We will use it on the first day of class, so make sure to have it installed.

**Success Criteria**: You can run the command `docker compose` in the terminal and it does not return an error.


### Windows

Install [scoop](https://scoop.sh/). See the instructions on the front page. You need to install it in Powershell but will then be able to use it in Git Bash and other terminals.


---

## SSH

Make sure that you have an SSH key pair generated. 

1. Make sure that you have an SSH key pair (public / private keys) locally that you can copy.

2. Make sure that you have added your public key to your GitHub account. You can do this by following the instructions [here](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/adding-a-new-ssh-key-to-your-github-account).

If you don't, then this tutorial will help you: [SSH Key Generation and Adding to GitHub](./SSH_Key_GitHub.md).


---

## Azure

Make sure that you have access to the Azure portal and that you have some credit left.

Try https://portal.azure.com to see if you can log in.

Make sure that your [Student Development Pack](https://education.github.com/pack) is active.
